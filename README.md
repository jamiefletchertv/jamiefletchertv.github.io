# jamiefletchertv.github.io
This repository is used as an umbrella repository for hosting the github
organization jamiefletchertv.github.io.

The branch `jamiefletcher.dev` of this repository
(jamiefletchertv.github.io) is used for github pages uses the custom domain
jamiefletcher.dev.

This means any repositories with gh-pages enabled (and no domain set) can be
accessed via my github organization jamiefletchertv.github.io (currently set
with the jamiefletcher.dev domain).

See
[here](https://stackoverflow.com/questions/68505452/github-pages-with-single-custom-subdomain-for-multiple-repositories-using-paths)
for more information.

Current setup:

Org/repo/branch
- jamiefletchertv/jamiefletchertv.github.io/jamiefletcher.dev (https://jamiefletcher.dev)
- jamiefletchertv/http.video (https://jamiefletcher.dev/http.video)

Hosted separately
- jamiefletchertv/jamiefletcher.tv (jamiefletcher.tv)
